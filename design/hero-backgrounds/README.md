# Hero background concepts

This collection contains 100 background concepts for the frontend developer portfolio. All variant names, navigation labels, and design controls are in English.

Open [hero-background-preview.html](./hero-background-preview.html) in a browser. Use the previous and next buttons or the named picker to compare concepts. The preview follows the system's light or dark appearance.

[hero-background-variants.html](./hero-background-variants.html) is the editable fragment for inline design reviews. The browser preview is a standalone snapshot of that fragment, including the preview runtime, portrait, and fonts. Regenerate it with the `visualize` renderer after editing the fragment.

These concepts are design references. They are not included in the Angular application or its production build.
